# HOWTO — швидкі сценарії

Короткі кроки для щоденної роботи. Повний опис UI: [USER_GUIDE.md](USER_GUIDE.md).

## Запуск GUI

```bash
cd java
./pingui-java.sh
```

Або з кореня репозиторію (якщо налаштовано обгортку):

```bash
./pingui.sh
```

Мова інтерфейсу: меню **Мова** або `./pingui-java.sh -- --lang en` (коди: `uk`, `en`, `es`, `it`, `pl`, `cs`, `lv`, `lt`, `et`).

## Додати ціль і почати моніторинг

1. У полі внизу списку введіть IPv4 / hostname.
2. **Додати** (або Enter).
3. Увімкніть чекбокс біля цілі — почнеться трасування / ping.
4. Виділіть рядок — справа з’явиться граф маршруту (у режимі з trace).

## Простий і розширений вигляд

- **Простий** — компактне вікно (~580 px), основні дії.
- **Розширений** — ширша панель, Expert ping, історія, додаткові інструменти.

Перемикач — у панелі режиму моніторингу (не плутати з меню **Мова**).

## Ping only

Для повільних середовищ (наприклад Windows / `tracert`) або коли потрібен лише RTT:

1. Відкрийте налаштування цілі / режим probe.
2. Увімкніть **Ping only** — без повного traceroute.

## Зберегти список цілей

**Зберегти** (або Ctrl/Cmd+S) записує список у YAML профілю, з яким запущено застосунок.

## SQLite і історія

За замовчуванням сесія в RAM. Опційна БД: меню **База даних…** або CLI `--session-db`. Історія змін маршруту доступна в розширеному режимі після увімкнення SQLite.
