## Apoyar el proyecto

Si este proyecto te resulta útil, puedes apoyar su desarrollo con una donación voluntaria en USDT.

Las donaciones son opcionales y no otorgan propiedad, participación, tokens, derechos de gobernanza, soporte de pago, prioridad de servicio ni ningún retorno de inversión.

Asegúrate de que la red elegida coincida con el tipo de dirección.
